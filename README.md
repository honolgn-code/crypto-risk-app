# 🚀 Crypto Risk Analysis App

An AI-powered web application for cryptocurrency market analysis and risk assessment.

## 🛠️ Tech Stack
* **Frontend:** React
* **Backend:** Vercel Serverless Functions (`/api/chat`)
* **AI Engine:** Google Gemini API

## 🔑 Setup & Deployment
To run this project on Vercel, make sure to add the following environment variable:

* `GEMINI_API_KEY`: Your Google Gemini API Key
